# Ягодное поле

Одностраничный сайт семейной ягодной фермы. Это статический сайт без сборки: откройте `index.html` через любой веб-сервер.

## Локальный запуск

```bash
python3 -m http.server 3000
```

Откройте `http://localhost:3000`.

## Как менять содержимое

- **Телефон, адрес и часы работы:** файл `content.js`, блок `contacts`. Пустые значения автоматически заменяются подписями «будет добавлен».
- **Новый товар:** скопируйте объект в массив `products` в `content.js` и измените название, описание, фото и параметры. Для свежих ягод используйте `category: "fresh"`, для заготовок — `category: "preserves"`.
- **Фотографии:** положите новые файлы в `assets` и укажите путь в `content.js` или `index.html`. Сохранённые имена можно оставить, заменив сами изображения.
- **Новый раздел:** добавьте секцию в `index.html` и ссылку в основное меню. Стили находятся в `styles.css`.

## Перед публикацией

1. Заполнить контакты и рабочие данные фермы в `content.js`.
2. Заменить демонстрационные фотографии собственными снимками поля, продукции и владельца.
3. Подключить формы к почте, CRM или мессенджеру. Сейчас заявки **не отправляются**: интерфейс честно сообщает о демонстрационном режиме и позволяет скопировать текст заявки.
4. Добавить реквизиты владельца и актуальную политику обработки персональных данных.
