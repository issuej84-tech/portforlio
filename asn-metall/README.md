# АСН МЕТАЛЛ

Статический сайт для GitHub Pages: `https://issuej84-tech.github.io/portforlio/asn-metall/`.

## Состав

`index.html`, `style.css`, `site.js`, `favicon.svg` и пять оптимизированных JPEG. Для локального просмотра: `python3 -m http.server 8765` из корня репозитория, затем `/asn-metall/`.

## Контент и контакты

Название и перечень производимых изделий предоставлены заказчиком. Проверенные телефон, адрес, ИНН, почта и мессенджер не найдены; контакты не выдуманы. Конструктор проекта скачивает TXT локально и не отправляет заявки. Для запуска приёма обращений нужны подтверждённый канал связи и обработчик формы. Изображения обозначены на странице как концепции, а не реализованные проекты. Нет фиктивных отзывов, цен, сроков или статистики.
