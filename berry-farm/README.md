# Сайт клубничной фермы «Ягодная поляна»

Одностраничный сайт-визитка: первый экран со сменяющимися фото, продукция, самосбор, «О нас», галерея, доставка, форма заявки и контакты.
Сделан на чистых HTML, CSS и JavaScript — без конструкторов, баз данных и платных сервисов.

**Демо:** https://issuej84-tech.github.io/portforlio/berry-farm/

> «Ягодная поляна», телефон, адрес, цены, имя владельца и все фото — **заглушки**. Перед запуском замените их (список — в конце).

---

## Из чего состоит

| Файл | Что внутри | Нужно ли трогать |
|---|---|---|
| `content.js` | **Все тексты, цены, кнопки, меню, фото, контакты** | Да, это ваш «пульт управления» |
| `img/` | Фотографии | Да — кладите сюда свои фото |
| `index.html` | Каркас страницы, заголовки разделов, название во вкладке | Редко |
| `style.css` | Цвета, шрифты, отступы | Редко (цвета — в самом верху) |
| `app.js` | Логика: слайдер, фильтр, галерея, форма | Обычно нет |
| `credits.html` | Авторы временных фото | Удалить, когда замените фото |

## Как посмотреть сайт у себя

1. Скачайте папку `berry-farm` целиком.
2. Откройте `index.html` двойным щелчком — сайт откроется в браузере.
3. Поменяли что-то в `content.js` → сохранили → обновили страницу (F5).

Редактировать удобнее всего в бесплатной программе **VS Code** (code.visualstudio.com): она подсвечивает ошибки и не портит кодировку. Блокнот Windows тоже подойдёт, но сохраняйте в UTF-8.

## Правила редактирования `content.js`

- Текст всегда в кавычках: `"Клубника свежая"`.
- После каждого поля и каждого элемента списка — запятая.
- Если сверху страницы появилась **красная полоса «Не удалось прочитать content.js»** — в последней правке потерялась кавычка или запятая. Отмените правку (Ctrl+Z) и попробуйте ещё раз.

## Частые задачи

### Поменять цену или описание
Найдите товар в разделе `products` и поменяйте `price`, `unit` или `text`:
```js
{ id: "strawberry", category: "fresh", title: "Клубника свежая", text: "Крупная сладкая ягода утреннего сбора.", price: "650 ₽", unit: "за кг", image: "img/p-strawberry.webp", badge: "Сезон" },
```

### Добавить товар
Скопируйте строку любого товара, вставьте ниже и поменяйте значения. `id` — любое уникальное слово латиницей.
```js
{ id: "compote", category: "preserves", title: "Компот из клубники", text: "Банка 1 л.", price: "300 ₽", unit: "за банку", image: "img/compote.webp" },
```
- `category`: `"fresh"` — свежие ягоды, `"preserves"` — заготовки. Можно добавить свою категорию в `productCategories`.
- Товар сам появится в каталоге и в списке формы заказа.

### Малина и голубика: «скоро» → «в продаже»
Сейчас у них стоит `available: false` и плашка «Скоро». Когда пойдёт урожай — удалите `available: false`, впишите `price` и `unit`, а в `badge` напишите, например, `"Новинка"`.

### Добавить кнопку в левое меню
В разделе `menu` добавьте строку:
```js
{ label: "Отзывы", href: "#reviews", icon: "star" },
```
`href` — это `#` и `id` раздела, к которому кнопка прокручивает страницу. Можно указать и внешнюю ссылку, например `"https://vk.com/..."`.
Иконки: `home, basket, hand, leaf, camera, truck, cart, pin, jar, star, phone`.

Верхнее меню настраивается так же — в разделе `topMenu`.

### Кнопки на первом экране
Раздел `hero.buttons`. У кнопки можно указать `method: "pickup"` / `"courier"` / `"pick"` — тогда в форме заказа сразу выберется самовывоз, доставка или самосбор.

### Добавить новый раздел (например, «Экскурсии» или «Отзывы»)
В конце `content.js` есть `customSections` с готовым примером. Уберите `//` в начале строк примера и поменяйте текст:
```js
customSections: [
  {
    id: "excursions",
    title: "Экскурсии на ферму",
    label: "Новое",
    text: "Проводим экскурсии для школ и детских садов.",
    image: "img/g-people.webp",
    button: { label: "Записаться", href: "#order" },
    addToMenu: true,   // кнопка сама появится в левом меню
    icon: "star",
  },
],
```
Разделов можно добавить сколько угодно — через запятую.

### Заменить фото
1. Сожмите фото на **squoosh.app** (формат WebP или JPG, ширина 1600–1920 px для первого экрана и 1000–1280 px для остальных). Так сайт будет быстро открываться с телефона.
2. Положите файл в папку `img/`. Имя — латиницей без пробелов: `pole-leto.webp`.
3. Пропишите путь в `content.js`: `image: "img/pole-leto.webp"`.

Где какие фото: `slides` — первый экран, `products` — карточки товаров, `pick.images` — самосбор, `about.owner.photo` — **фото владельца**, `gallery` — галерея, `delivery.image` — блок доставки.

Когда все временные фото заменены на свои — удалите блок `credits` в `content.js` и файл `credits.html`.

### Заявки в Telegram или WhatsApp
Форма работает без сервера: собирает заявку в готовый текст и предлагает отправить его в мессенджер, позвонить или скопировать.
В `contacts` впишите:
```js
telegram: "berry_farm",      // ник без @
whatsapp: "79001234567",     // номер только цифрами
```
Появятся кнопки «Telegram» и «WhatsApp» — откроется чат фермы с уже написанным сообщением. Пустое значение — кнопки нет.

### Карта
Откройте yandex.ru/maps → найдите ферму → «Поделиться» → «Виджет с картой» → скопируйте ссылку из `src="..."` и вставьте в `mapEmbed`.

### Название во вкладке браузера и в поиске
Это в `index.html`, строки `<title>` и `<meta name="description">` в самом начале файла.

### Цвета и шрифты
В самом верху `style.css`: `--red` — кнопки, `--green` — меню и тёмные блоки, `--cream` — фон.

## Публикация сайта

### Вариант 1. Уже работает: GitHub Pages этого портфолио
Сайт лежит в папке `berry-farm` репозитория `portforlio`. Когда изменения попадают в ветку `main`, GitHub сам обновляет сайт за 1–2 минуты:
**https://issuej84-tech.github.io/portforlio/berry-farm/**

### Вариант 2. Отдельный сайт клиента на GitHub Pages (бесплатно)
1. На github.com создайте новый репозиторий, например `berry-farm`.
2. Загрузите в него **содержимое** папки `berry-farm` (кнопка «Add file → Upload files»): `index.html`, `content.js`, `app.js`, `style.css`, папку `img`.
3. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
4. Через пару минут сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/berry-farm/`.

Править потом можно прямо на github.com: откройте `content.js` → карандаш ✏️ → «Commit changes». Сайт обновится сам.

### Свой домен (например, yagodnaya-polyana.ru)
1. Купите домен у регистратора (REG.RU, RU-CENTER и т. п.).
2. В GitHub: **Settings → Pages → Custom domain** → впишите домен → Save.
3. У регистратора в настройках DNS добавьте:
   - четыре записи `A` для самого домена: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   - запись `CNAME` для `www` → `ВАШ-ЛОГИН.github.io`.
4. Когда домен заработает, включите **Enforce HTTPS** в тех же настройках (может стать доступно не сразу, до 24 часов).

Инструкция GitHub: https://docs.github.com/ru/pages/configuring-a-custom-domain-for-your-github-pages-site

### Вариант 3. Обычный хостинг
Подойдёт любой хостинг для статичных сайтов (Beget, Timeweb, REG.RU и др.): в файловом менеджере хостинга загрузите содержимое папки `berry-farm` в папку сайта (обычно `public_html`). Ничего устанавливать не нужно.

### После запуска
- Добавьте сайт в **Яндекс Вебмастер** (webmaster.yandex.ru), чтобы его быстрее нашли в поиске.
- Заведите карточку фермы в **Яндекс Бизнесе / Картах** и укажите там ссылку на сайт — по запросам «клубника самосбор рядом» люди ищут именно в картах.

## Что заменить перед запуском

- [ ] Название фермы — `brand` в `content.js` и `<title>` в `index.html`
- [ ] Телефон, адрес, часы работы, Telegram/WhatsApp — `contacts`
- [ ] Карта — `mapEmbed`
- [ ] Цены и описания — `products`, `pick`, `delivery`
- [ ] Имя, фото и цитата владельца, история фермы — `about`
- [ ] Годы и планы — `about.timeline`
- [ ] Свои фото вместо временных, затем удалить `credits` и `credits.html`
- [ ] Плашка сезона — `season` (`open: false`, когда сезон закрыт)

Временные фото взяты с Wikimedia Commons по свободным лицензиям — авторы указаны в `credits.html`.
